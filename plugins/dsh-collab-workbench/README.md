# dsh-collab-workbench

Pluginmax 工作台（我的工作台 / 管理驾驶舱）。它承接全局 `workbench`
路由，替换此前由 `dsh-collab-employee` 在该路由上渲染的员工平台页（该页面
实现仍保留在员工插件内，等待后续复用）。

职责：

- 我的工作台：核心指标、每日简报、我的待办、重点关注、会议纪要、供给例外、
  供应商风险七个模块，支持标题栏拖拽排序、六档宽度与高度调整、模块级刷新、
  布局保存 / 切换 / 设默认 / 恢复默认（布局偏好存 `localStorage`）。
- 管理驾驶舱：首版只保留模式入口与占位容器，不请求业务数据。
- 关注：任务与工作流的关注 / 取消关注持久化（`collab_workbench` 域），任务与
  工作流页面通过 `/api/collab/workbench/follows/toggle` 读写同一份状态。
- 每日简报：拉取式增量合并（离开窗口、A / B / C 三区准入、已读 / 未读模型、
  优先级排序），模块右上角手动刷新复用同一合并逻辑。

## 后续（已与产品确认，待下一步实现）

- 简报事件驱动的 diff 推送（页面自动更新）尚未实现；当前只有拉取式合并与手动
  刷新。补推送时需要：领域事件 → 对该读者重新执行增量合并 → 计算 diff →
  推送到当前打开简报的页面会话（不做通知中心、不做站外推送）。
- 核心指标、供给例外、供应商风险目前使用工作台聚合 API 的演示 / 种子数据，
  待真实业务域接入后替换。
