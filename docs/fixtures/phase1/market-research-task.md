1. 最终产出一份 Markdown 竞品调研分析。
2. 事实性结论必须带公开来源 URL、发布日期和访问时间。
3. 不允许读取本地私有文件或个人数据。
4. 最终文本必须包含标记 `PHASE1_RESEARCH_DONE`、`PHASE1_SOURCE_POLICY_SEEN=YES` 和 `PHASE1_FEEDBACK_SEEN=<token>`。

- 有明确的竞品对比表、机会判断与产品建议。
